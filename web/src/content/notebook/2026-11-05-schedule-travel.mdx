outcome: Rejected

## Hypothesis

Fatigue and travel are a staple of NBA analysis: the fourth game in six nights, a West Coast trip, a team flying in from three time zones away. Some arenas, Denver and Utah in particular, are also said to give a bigger home edge than others. If any of that is real and the model does not already capture it, adding it should help.

## What the model already knows

Rest is already in the model, as days since each team's last game (capped at 5) plus a flag for a team playing on consecutive nights.

Home advantage is already in two places: the 70-point home bonus inside the Elo gap, and the model itself, which learns home and away scores separately.

## What was tested

Each candidate was added on its own to the lean feature set and run through the same paired walk-forward cross-validation (three seeds) used for every feature decision:

| Candidate | Definition |
|---|---|
| Schedule load | Games played in the previous 4 nights, and in the previous 6 nights |
| Travel | Miles between the previous game's arena and tonight's, and time zones crossed |
| Per-team home court | Each team's own historical home-minus-road margin, in place of one league-wide edge |

## Finding

None improved margin error or winners picked. The result is recorded next to the feature list in the code, so the same ideas are not re-tested by accident.

The most likely reason is overlap. Heavy schedule stretches usually include a back-to-back, which the model already sees. Per-team home strength is a small number estimated from a few hundred games, so it is mostly noise.
